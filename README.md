# FPS1

A small Godot 4 first-person shooter starter project.

## Requirements

- Godot 4.3 or newer

## Getting started

1. Import this repository in the Godot Project Manager.
2. Run the project with `F6` from `scenes/main.tscn`, or press `F5` to run the main scene.
3. Click the game window if the mouse is unlocked.

## Controls

- `WASD` — move
- Mouse — look
- `Space` — jump
- `Esc` — release or recapture the mouse

The starter scene builds a small training arena at runtime, including cover, lighting, a first-person camera, a crosshair, and the market cottage model in `models/market_cottage.glb`. The cottage is scaled to approximately real-world proportions, with a roughly 2-meter doorway.
