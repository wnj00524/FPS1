# FPS1

A small Unity first-person shooter starter project.

## Requirements

- Unity 2022.3 LTS or newer

## Getting started

1. Open the repository folder in Unity Hub.
2. Open `Assets/Scenes/FPSDemo.unity`.
3. Press Play.

## Controls

- `WASD` — move
- Mouse — look
- `Space` — jump
- `Esc` — unlock the cursor

The project intentionally keeps the foundation small so weapons, enemies, levels, and game modes can be added without removing starter code.
